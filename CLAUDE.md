# Regras do projeto

## Instalação de skills
Antes de recomendar ou instalar qualquer skill (via `find-skills`, `npx skills`, ou
cópia manual), mostrar sempre o Relatório de Segurança completo definido em
`.claude/skills/find-skills/SKILL.md` (autor, repositório, instalações, estrelas,
issues/comentários, ficheiros, red flags, veredicto) e esperar pelo "sim" explícito
do utilizador. Nunca usar `-y`.
